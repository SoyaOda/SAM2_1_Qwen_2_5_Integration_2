# Qwen2.5-VL バッチ処理仕様まとめ

## 4:1パッチ圧縮
- Vision Towerが2×2パッチマージを行うため、4パッチ→1トークンに圧縮
- パッチ数は必ず4の倍数にパディング

## バッチ内統一処理
1. バッチ内の最大グリッドサイズを計算
2. グリッドサイズを4の倍数に調整
3. すべてのサンプルを同じグリッドサイズにパディング
4. image_grid_thwもすべて統一された値に設定

## 現在の実装状況
- トレーニングは正常に動作
- 4:1圧縮は正しく実装済み
- ただし、バッチ内で個別のグリッドサイズが保持されている（統一されていない）
